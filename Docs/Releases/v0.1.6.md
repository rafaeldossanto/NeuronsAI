# NeuronsAI v0.1.6

O card do ChatGPT passa a encontrar o Codex que vem no app do Codex no Windows.

## O que mudou

**Conexões: ChatGPT (Codex)**

- No Windows, sem o Codex CLI instalado, o NeuronsAI usa o Codex que o app desktop do Codex já traz, e não precisa mais de `npm i -g @openai/codex` só para conectar.
- O login continua sendo o oficial do Codex (Sign in with ChatGPT), o mesmo para o app e para o CLI. O NeuronsAI não lê nem guarda as credenciais.
- O CLI instalado (PATH, npm) e o caminho em `NEURONS_CODEX_BIN` continuam com prioridade.
- Os textos do card agora citam o app do Codex ou o Codex CLI.

**macOS e Linux**

- Sem mudança: continuam precisando do Codex CLI.

## Limitações conhecidas

- Os instaladores continuam sem assinatura de código ou notarização.
- A integração do Codex continua experimental, com testes automatizados usando CLI simulada. A aceitação real (rodar um grafo com a assinatura) ainda não foi feita.
- A cópia do app fica numa pasta interna dele (`.codex\.sandbox-bin`), que a OpenAI não documenta: pode ser uma versão alfa ou mais antiga que a do npm, uma atualização do app pode mudá-la, e se ela sumir o card volta a pedir o CLI.
- O `codex.exe` de dentro da pasta do app da Microsoft Store não pode ser usado, porque o Windows bloqueia.
- A aceitação manual de instalação e atualização nos três sistemas permanece separada dos testes automatizados de empacotamento.
- Os botões por papel da exclusão (pedir, aprovar, recusar) só foram conferidos em testes automatizados, não na tela com login.
- A janela foi conferida no Windows 10, não no Windows 11.
- No Windows 11, o menu de layouts que aparece ao parar o mouse sobre o botão de maximizar não aparece, porque a janela não usa a moldura nativa.
- As demais limitações da [v0.1.2](v0.1.2.md#limitações-conhecidas) permanecem aplicáveis.
