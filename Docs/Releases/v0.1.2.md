# NeuronsAI v0.1.2

Atualização sobre a v0.1.1 que permite usar a assinatura do ChatGPT nos agentes de terminal.

## O que mudou desde a v0.1.1

- **Conta do ChatGPT pelo Codex CLI (experimental):** os agentes de terminal agora podem usar o Codex CLI oficial (`@openai/codex`) com a assinatura do ChatGPT, nos modos `stream-json` e `pty`. O card "ChatGPT" em Conexões mostra a instalação, o login oficial (`codex login`) e o status. O agente roda com sandbox somente leitura, e o NeuronsAI não lê nem guarda os tokens do Codex. A chave de API no Codex vale apenas no modo `stream-json`.
- **Instaladores de Linux:** os arquivos já saem com o nome `linux-x64`.

## Limitações conhecidas

- A integração com o Codex foi testada apenas com uma CLI simulada, não com o Codex real; trate-a como experimental.
- No `stream-json` do Codex o texto chega por mensagem inteira, não token por token.
- Servidores MCP já configurados no `~/.codex/config.toml` do usuário também são carregados pelo Codex.
- Ainda sem assinatura de código ou notarização. Windows e macOS podem exibir avisos de segurança.
- O streaming token por token dos demais provedores foi testado apenas com provedores simulados, não com os serviços reais.
- Claude Code ou Codex precisam estar instalados e autenticados para executar agentes de terminal. Gemini e terminais personalizados ainda não têm adaptadores de execução.
- Provedores de API precisam de configuração e podem gerar cobranças do respectivo fornecedor. O custo de agentes PTY não é informado; estimativas de API se limitam ao catálogo conhecido.
- Agendas e gatilhos locais dependem do aplicativo aberto. WhatsApp e login Google exigem configuração externa; a aceitação com esses serviços reais permanece pendente.
- A conexão remota do desktop não inicia automaticamente um runner local.
- A aceitação manual de instalação e atualização nos três sistemas continua separada dos testes automatizados de empacotamento. macOS sem assinatura e Linux deb usam atualização por download manual.
- A landing e a hospedagem em nuvem não fazem parte desta publicação.
