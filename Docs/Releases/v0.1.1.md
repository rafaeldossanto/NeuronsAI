# NeuronsAI v0.1.1

Atualização de desempenho e de respostas ao vivo sobre a v0.1.0.

## O que mudou desde a v0.1.0

- **Respostas token por token:** os agentes de API (OpenAI, Anthropic e serviços compatíveis com OpenAI) e os agentes de terminal em `stream-json` agora mostram o texto conforme ele é gerado, em vez de esperar a resposta completa. O runner passa a enviar o frame `agent.delta` (protocolo na revisão 6, compatível com as anteriores).
- **Servidor mais rápido com muitos dados:** a lista de execuções calcula o custo só da página exibida, `GET /runs/:id` usa um agregado, o replay do WebSocket é feito em lotes, há índices novos no banco (migration `0015_query_indexes`), a limpeza de webhooks é limitada e o pool do Postgres é configurável.
- **Menos espera em cada requisição:** uma única leitura de membro por requisição, status do Claude com cache de 30 s, timeout na conexão com servidores MCP e registro de requisições lentas.
- **Web e site mais leves:** a entrada da web caiu de cerca de 1.239 kB para 428 kB e o JavaScript inicial do site, de 144 kB para 20 kB, com carregamento sob demanda e menos re-renderizações.

## Limitações conhecidas

- Ainda sem assinatura de código ou notarização. Windows e macOS podem exibir avisos de segurança.
- O streaming token por token foi testado apenas com provedores simulados, não com os serviços reais.
- Claude Code precisa estar instalado e autenticado para executar agentes de terminal. Codex, Gemini e terminais personalizados ainda não têm adaptadores de execução.
- Provedores de API precisam de configuração e podem gerar cobranças do respectivo fornecedor. O custo de agentes PTY não é informado; estimativas de API se limitam ao catálogo conhecido.
- Agendas e gatilhos locais dependem do aplicativo aberto. WhatsApp e login Google exigem configuração externa; a aceitação com esses serviços reais permanece pendente.
- A conexão remota do desktop não inicia automaticamente um runner local.
- A aceitação manual de instalação e atualização nos três sistemas continua separada dos testes automatizados de empacotamento. macOS sem assinatura e Linux deb usam atualização por download manual.
- A landing e a hospedagem em nuvem não fazem parte desta publicação.
