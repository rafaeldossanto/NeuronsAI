# NeuronsAI v0.1.0

Primeira versão pública do NeuronsAI, um orquestrador visual de agentes de IA.

## Incluído nesta versão

- Editor visual de projetos, templates, anotações e publicação de grafos.
- Execução ao vivo com mensagens, terminais, histórico e replay.
- Agentes de API com OpenAI, Anthropic e serviços compatíveis com OpenAI; agentes de terminal com Claude Code.
- Ferramentas MCP, HTTP e memórias em Obsidian, com permissões por ligação.
- Aplicativo desktop com servidor local e banco PGlite embutidos.
- Agendas, webhooks e integração com WhatsApp, mediante configuração.
- Conexão com servidor remoto, organizações, convites e runners separados.

## Limitações conhecidas

- Versão inicial, ainda sem assinatura de código ou notarização. Windows e macOS podem exibir avisos de segurança.
- Claude Code precisa estar instalado e autenticado para executar agentes de terminal. Codex, Gemini e terminais personalizados ainda não têm adaptadores de execução.
- Provedores de API precisam de configuração e podem gerar cobranças do respectivo fornecedor. O custo de agentes PTY não é informado; estimativas de API se limitam ao catálogo conhecido.
- Agendas e gatilhos locais dependem do aplicativo aberto. WhatsApp e login Google exigem configuração externa; a aceitação com esses serviços reais permanece pendente.
- A conexão remota do desktop não inicia automaticamente um runner local.
- A aceitação manual de instalação e atualização nos três sistemas continua separada dos testes automatizados de empacotamento. macOS sem assinatura e Linux deb usam atualização por download manual.
- A landing e a hospedagem em nuvem não fazem parte desta publicação.
