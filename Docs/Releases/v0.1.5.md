# NeuronsAI v0.1.5

A janela do Windows volta a ter cantos arredondados.

## O que mudou

**App desktop no Windows**

- A janela volta a ter cantos arredondados, como até a v0.1.3.
- Os controles de minimizar, maximizar/restaurar e fechar ficam à direita, no estilo do Windows: sem cor em repouso, cinza leve ao passar o mouse e fechar vermelho.
- Duplo clique na barra maximiza e restaura a janela.
- Maximizada, a janela fica sem cantos arredondados.

**macOS e Linux**

- Sem mudança.

## Downloads

Os arquivos estão na [release v0.1.5](https://github.com/rafaeldossanto/NeuronsAI/releases/tag/v0.1.5).

| Sistema | Arquivo |
| --- | --- |
| Windows x64 | `NeuronsAI-0.1.5-win-x64.exe` |
| macOS Apple Silicon | `NeuronsAI-0.1.5-mac-arm64.dmg` |
| macOS Intel | `NeuronsAI-0.1.5-mac-x64.dmg` |
| Linux x64 | `NeuronsAI-0.1.5-linux-x64.AppImage` ou `NeuronsAI-0.1.5-linux-x64.deb` |

Os ZIPs do macOS, metadados de atualização e `SHA256SUMS.txt` acompanham os instaladores. Instruções de primeira abertura e conferência dos arquivos no [README do desktop](../../apps/desktop/README.md#primeira-abertura-sem-assinatura-para-a-página-de-download).

## Limitações conhecidas

- Os instaladores continuam sem assinatura de código ou notarização.
- A integração do Codex CLI continua experimental, com testes automatizados usando CLI simulada.
- A aceitação manual de instalação e atualização nos três sistemas permanece separada dos testes automatizados de empacotamento.
- Os botões por papel da exclusão (pedir, aprovar, recusar) só foram conferidos em testes automatizados, não na tela com login.
- A janela nova foi conferida no Windows 10, não no Windows 11.
- No Windows 11, o menu de layouts que aparece ao parar o mouse sobre o botão de maximizar não aparece mais, porque a janela não usa a moldura nativa.
- As demais limitações da [v0.1.2](v0.1.2.md#limitações-conhecidas) permanecem aplicáveis.
