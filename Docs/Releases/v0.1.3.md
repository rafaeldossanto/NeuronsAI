# NeuronsAI v0.1.3

Atualização visual sobre a v0.1.2, com cabeçalho compacto, menu de conta e o novo ícone aprovado.

## O que mudou

- Cabeçalho com Meus projetos e Execuções, liberando espaço para o conteúdo.
- Menu de conta com conexões de IA, chaves de API, conexão com servidor e configurações locais. Com sessão autenticada, também reúne organizações, runners e saída da conta.
- Retorno ao espaço local disponível na tela de entrada remota, inclusive quando a sessão expirou.
- Ícone de núcleo de partículas com fundo transparente no aplicativo, no cabeçalho e no favicon.
- Paleta clara com destaques em âmbar preservada.

A integração do ChatGPT pelo Codex CLI da v0.1.2 permanece disponível. As opções de IA e chaves abrem o painel de conexões existente. A barra interna de ferramentas do editor mantém a organização anterior.

## Downloads

Os arquivos estão na [release v0.1.3](https://github.com/rafaeldossanto/NeuronsAI/releases/tag/v0.1.3).

| Sistema | Arquivo |
| --- | --- |
| Windows x64 | `NeuronsAI-0.1.3-win-x64.exe` |
| macOS Apple Silicon | `NeuronsAI-0.1.3-mac-arm64.dmg` |
| macOS Intel | `NeuronsAI-0.1.3-mac-x64.dmg` |
| Linux x64 | `NeuronsAI-0.1.3-linux-x64.AppImage` ou `NeuronsAI-0.1.3-linux-x64.deb` |

Os ZIPs do macOS, metadados de atualização e `SHA256SUMS.txt` acompanham os instaladores. Instruções de primeira abertura e conferência dos arquivos no [README do desktop](../../apps/desktop/README.md#primeira-abertura-sem-assinatura-para-a-página-de-download).

## Limitações conhecidas

- Os instaladores continuam sem assinatura de código ou notarização.
- A integração do Codex CLI continua experimental, com testes automatizados usando CLI simulada.
- A aceitação manual de instalação e atualização nos três sistemas permanece separada dos testes automatizados de empacotamento.
- As demais limitações da [v0.1.2](v0.1.2.md#limitações-conhecidas) permanecem aplicáveis.
