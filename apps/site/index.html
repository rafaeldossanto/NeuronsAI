Como instalar

O aplicativo ainda não é assinado. Por isso, o Windows e o macOS podem exibir um aviso na primeira abertura.

01

Windows

Abra o instalador .exe e siga as etapas. Se o SmartScreen mostrar “O Windows protegeu seu computador”, escolha Mais informações → Executar assim mesmo.

Conferir SHA256 no Windows

Baixe também o SHA256SUMS.txt da mesma release. No PowerShell, dentro da pasta dos downloads, substitua VERSAO pelo nome exato do arquivo: 

certutil -hashfile ".\NeuronsAI-VERSAO-win-x64.exe" SHA256
Get-Content .\SHA256SUMS.txt

Compare o hash exibido com a linha do mesmo instalador no SHA256SUMS.txt. Eles devem ser iguais.

02

macOS

Abra o .dmg e arraste NeuronsAI para Aplicativos. Se baixou o ZIP, descompacte e mova o aplicativo para essa pasta.

Na primeira abertura, clique com o botão direito no aplicativo e escolha Abrir. Outra opção é Ajustes do Sistema → Privacidade e Segurança → Abrir mesmo assim.

Conferir SHA256 no macOS

Baixe o SHA256SUMS.txt da mesma release. No Terminal, dentro da pasta dos downloads, use o nome exato do arquivo e a arquitetura escolhida: 

shasum -a 256 "NeuronsAI-VERSAO-mac-arm64.dmg"
cat SHA256SUMS.txt

Compare o hash com a linha correspondente no SHA256SUMS.txt. Para Intel, use o arquivo x64; o procedimento também vale para ZIP.

03

Linux

Para AppImage, dê permissão de execução e abra o arquivo:

chmod +x NeuronsAI-*.AppImage
./NeuronsAI-*.AppImage

Para Debian ou Ubuntu, instale o pacote .deb:

sudo apt install ./NeuronsAI-*.deb
Conferir SHA256 no Linux

Salve o instalador e o SHA256SUMS.txt da mesma release na mesma pasta. No terminal, execute: 

sha256sum --ignore-missing -c SHA256SUMS.txt

O arquivo baixado deve aparecer com resultado OK. Os arquivos da release que não estiverem na pasta serão ignorados.

Confira o SHA256 antes de abrir o instalador. Se o hash não for igual, descarte o download e consulte os arquivos da release.

Perguntas frequentes

Antes de conectar

Como os agentes se comunicam?

As conexões do grafo representam os caminhos entre os agentes. Cada agente tem um papel e pode repassar contexto e atividades para o próximo, mantendo o fluxo visível.

Posso usar modelos diferentes?

Essa é a proposta do NeuronsAI: definir o modelo, o esforço e o contexto de cada agente de forma independente, reunindo diferentes papéis no mesmo grafo.

Quais ferramentas posso conectar?

O projeto prevê conexões com MCPs, APIs e fontes de conhecimento, incluindo notas do Obsidian. Na demonstração acima, você pode explorar como essas ferramentas se relacionam com os agentes.

Como acompanho as execuções?

O grafo organiza os agentes e seus repasses em uma visão única. Use o botão de reprodução no exemplo acima para visualizar uma simulação do caminho entre o pedido e a entrega.
